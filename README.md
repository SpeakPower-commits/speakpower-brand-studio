# SpeakPower Brand Promotion Studio

An online campaign-planning workspace for SpeakPower.

## Files
- `app.py` — the Gradio application
- `brand_config.py` — SpeakPower brand identity and content rules
- `requirements.txt` — application dependencies

The first version creates structured campaign briefs. An AI model will
be connected in the next development stage using a Hugging Face secret.
Never put an API token directly in these files.
